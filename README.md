# ENSAT Data Toolbox

## Federation of Scripts for the Federation of Data

The **ENSAT Data Toolbox** is a research software repository developed to support the broader **Federation of Data** concept in adrenal tumour research.

The repository contains tools and supporting resources for data harmonisation, migration, version tracking, and conversion across evolving data structures and research environments.

## Repository Content

This repository will include:

- reusable scripts and utilities
- data-model and schema resources
- mapping and transformation specifications
- documentation
- synthetic examples
- testing and validation resources

## Scope

The toolbox is intended to support interoperable and reproducible data workflows across centres, projects, and database versions, while preserving traceability and provenance.

## Status

Research software under active development.

Individual tools may be experimental and should be reviewed and validated before use in production research environments.

## Data Protection

No identifiable or patient-level clinical data should be committed to this repository.

→ legacy ENS@T data conversion

→ semantically harmonised and reusable distributed research data

The objective is to allow the data model to evolve while preserving the connection between historical data, current definitions, and future research projects.
